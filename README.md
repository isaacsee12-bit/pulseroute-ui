# PulseRoute UI

A high-fidelity React/Vite implementation of the PulseRoute transit disruption dashboard concept.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in your terminal.

## Build

```bash
npm run build
```

## Stack

- React
- Vite
- Lucide React icons
- Plain CSS
- Inline SVG/CSS charts and transit map mockup

The current version is a front-end UI prototype with demo data only.
