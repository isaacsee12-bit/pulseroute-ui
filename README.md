# PulseRoute UI

A high-fidelity React/Vite dashboard for disruption-aware public-transport journey planning, rebuilt from the supplied PulseRoute visual reference.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The interface includes a responsive top navigation, trip planner, disruption alert, ranked route recommendations, interactive route selection, stylised route map, passenger-impact context, station crowding status, and alternative-route panels.
